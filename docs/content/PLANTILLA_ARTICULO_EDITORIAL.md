# Plantilla editorial para un artículo

## Ficha antes de escribir

- Pregunta concreta del lector:
- Intención de búsqueda: informativa / comparación / solución / compra informada
- Público y contexto dominicano:
- Palabra clave principal y 3 variantes naturales:
- Qué experiencia propia aporta Andy:
- Riesgo YMYL: bajo / medio / alto
- Producto relacionado (opcional):
- Acción final: leer otro artículo / WhatsApp / MyShop

## Fuentes mínimas

- Una fuente institucional o regulatoria primaria.
- Una guía o revisión científica reciente cuando haya afirmaciones de salud.
- Una fuente dominicana para estadísticas locales, si existe.
- La ficha oficial del fabricante solo para composición, uso o características del producto.

Registrar título, institución, URL, fecha y afirmación que respalda. No escribir “según estudios” sin enlace identificable.

## Estructura

1. Título que responda una necesidad real, sin promesas absolutas.
2. Resumen de 2–3 frases con respuesta directa.
3. Contexto dominicano y por qué importa.
4. Explicación en secciones H2, con párrafos cortos.
5. Riesgos, límites, contraindicaciones o cuándo buscar ayuda.
6. Pasos prácticos que el lector pueda aplicar.
7. Preguntas frecuentes no repetidas del cuerpo.
8. Fuentes consultadas.
9. Divulgación comercial y CTA proporcionado.

## Control antes de publicar

- [ ] La pieza aporta algo propio y no resume diez páginas ajenas.
- [ ] Los datos, porcentajes y recomendaciones tienen fuente.
- [ ] No diagnostica ni promete curar, prevenir o garantizar resultados.
- [ ] La relación comercial está visible.
- [ ] Título, extracto y meta descripción son distintos y precisos.
- [ ] Imagen original WebP 1200×630, menos de 200 KB y sin texto incrustado.
- [ ] Alt describe la imagen; no repite palabras clave.
- [ ] Hay 2–4 enlaces internos útiles y todos funcionan.
- [ ] La fecha y el responsable de revisión son reales.
- [ ] Se ejecutó `npm run content:check`.

La longitud debe ser la necesaria para resolver la pregunta. No existe un mínimo oficial de palabras de Google o AdSense.
