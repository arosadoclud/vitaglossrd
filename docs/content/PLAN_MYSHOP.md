# Plan de preparación de MyShop

Este plan se completa dentro de la cuenta oficial de Amway después de iniciar sesión.

## Objetivo

Configurar MyShop como el destino transaccional autorizado y utilizar VitaGloss RD y las redes para educar y orientar, sin duplicar información contradictoria.

## Configuración que se debe revisar

1. Nombre público permitido y divulgación como Empresario Independiente de Amway.
2. URL personal de MyShop.
3. Fotografía de perfil propia y profesional, sin logotipos Amway ni imágenes de producto como avatar.
4. Datos de contacto y horarios.
5. Métodos y zonas de entrega disponibles en la plataforma.
6. Políticas de devolución y garantía mostradas por Amway.
7. Categorías y productos disponibles para República Dominicana.
8. Enlaces sociales permitidos.
9. Vista móvil y proceso de compra.

## Colecciones sugeridas

Crear colecciones solo si MyShop ofrece esta función y conserva los textos oficiales:

- Cuidado bucal diario.
- Vitaminas y suplementos.
- Rutinas de bienestar.
- Opciones para comenzar.
- Productos más consultados.

No crear nombres que prometan tratar enfermedades, perder peso garantizado, curar condiciones o producir resultados en plazos concretos.

## Selección inicial

Priorizar un catálogo corto de productos que Andy conoce bien y puede explicar usando fuentes oficiales. Para cada producto guardar:

- SKU.
- URL oficial de MyShop.
- Descripción oficial vigente para RD.
- Instrucciones oficiales.
- Imagen o pieza aprobada descargable.
- Fecha de última revisión.
- Preguntas habituales de clientes.

## Enlaces

- Biografía pública: URL de MyShop y CTA permitido.
- Publicaciones públicas: no repetir el enlace ni CTA si las pautas lo restringen.
- Entornos privados: compartir la URL del producto o colección cuando exista interés.
- VitaGloss RD: definir si cada ficha llevará al producto equivalente de MyShop o a una conversación privada, evitando precios contradictorios.

## Control de calidad

- Probar el enlace en una sesión sin autenticar.
- Probar búsqueda, carrito y checkout en móvil.
- Confirmar que disponibilidad, SKU y producto coinciden.
- No copiar precios de MyShop al sitio público; se mantienen ocultos.
- Revisar mensualmente enlaces rotos y productos discontinuados.

## Estado de acceso

El portal oficial de Amway abre correctamente, pero requiere iniciar sesión con el Amway ID de Andy antes de localizar y configurar MyShop.
